# 🏨 One Night Stay

One Night Stay is a full-stack hotel and resort booking web application inspired by Airbnb. 
It provides a complete booking platform where users can browse properties, book stays, make secure online payments, and manage their bookings.
The application also includes dedicated dashboards for Hosts and Admins with role-based access control.

# 🚀 Features

### 👤 User Features
- User Registration & Login
- JWT Authentication
- Browse Hotels & Resorts
- Search & Sort Properties
- Property Details with Images
- Add to Wishlist
- Book Properties
- Razorpay Payment Integration
- Booking History
- Payment History
- Submit Reviews & Ratings
- Profile Management

---

### 🏠 Host Features
- Become a Host
- Add New Properties
- Upload Multiple Property Images
- View Own Properties
- View Customer Bookings
- Approve / Reject Bookings
- View Property Reviews
- View Payment History

---

### 👨‍💼 Admin Features
- Manage Users
- Manage Hosts
- Approve Host Requests
- Approve Subscription Requests
- View All Properties
- View All Bookings
- View All Payments
- View All Reviews

# ⚙ Installation

## Clone Repository

```bash
git clone https://github.com/yourusername/One_Night_Stay.git
```

## Backend

```bash
cd Backend/project
```

Create Virtual Environment

```bash
python -m venv env
```

Activate

Windows

```bash
env\Scripts\activate
```

Install Dependencies

```bash
pip install -r requirements.txt
```

Run Server

```bash
python manage.py runserver
```

---

## Frontend

```bash
cd Frontend/one-night-stay


Install Packages

```bash
npm install


Run Project

```bash
npm run dev
